<task type="auto">
  <name>Task 1: Create shared JsonResponse utility and refactor session validation</name>
  <files>Utils/JsonResponse.cs, Utils/Auth.cs, Controllers/Templates.cs, Controllers/HomeController.cs, Controllers/UserController.cs, Controllers/Question.cs, Controllers/ResponseController.cs</files>
  <action>
    1. Create `Utils/JsonResponse.cs` with a static helper class `JsonResponse` that provides methods:
       - `Ok(object data)` — returns `new JsonResult(new { data }) { StatusCode = 200 }`
       - `Error(string message, int statusCode = 400)` — returns `new JsonResult(new { errorMsg = message, status = statusCode }) { StatusCode = statusCode }`
       - `NotFound(string message)` — returns `new JsonResult(new { errorMsg = message }) { StatusCode = 404 }`
       This replaces all manual `JsonSerializer.Serialize(new { data = ... })` and `JsonSerializer.Serialize(new { errorMsg = ... })` patterns across all controllers.

    2. Refactor `Utils/Auth.cs` — The existing `ValidateUserSession` method redirects on failure, but controllers need to return JSON 401 responses instead. Add a new method `ValidateSession(HttpContext)` that returns `Models.User?` (null if invalid) WITHOUT redirecting. Keep the existing method for view-based actions.

    3. Refactor ALL controllers to use the shared helpers:
       - Replace every inline session validation block (`if(userSession == null || userSession.Email == null ...)`) with a call to `Auth.ValidateSession(HttpContext)` or the existing `Session.GetObject<User>()` followed by a null check using `JsonResponse.Error("Login to complete this action", 401)`.
       - Replace every `JsonSerializer.Serialize(new { data = ... })` with `JsonResponse.Ok(...)`.
       - Replace every `JsonSerializer.Serialize(new { errorMsg = ... })` with `JsonResponse.Error(...)`.
       - Replace every `BadRequest(JsonSerializer.Serialize(...))` with `JsonResponse.Error(msg, 400)`.
       - Replace every `NotFound(JsonSerializer.Serialize(...))` with `JsonResponse.NotFound(msg)`.

    4. In `Templates.cs` specifically:
       - The `LikeAction` method has identical if/else branches for "like" and "unlike" (lines 143-155) — consolidate into a single response after calling `_TemplateService.LikeAction()`.
       - Remove all `Console.WriteLine()` statements.
  </action>

  </verify>
  <done>
    - All controllers compile without errors
    - No inline `JsonSerializer.Serialize(new { data = ... })` or `JsonSerializer.Serialize(new { errorMsg = ... })` remain in any controller
    - No duplicated session validation blocks remain (all use shared helper)
    - LikeAction has a single response path instead of duplicated branches
    - `Utils/JsonResponse.cs` exists with Ok, Error, NotFound methods
  </done>
</task>

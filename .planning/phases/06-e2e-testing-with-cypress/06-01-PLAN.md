2. Add npm scripts to package.json:

   - "cypress:run": "cypress run"
3. Create cypress.config.js with:
   - e2e.baseUrl: "http://localhost:5000" (or the port from launchSettings.json)
   - e2e.viewportWidth: 1280
   - e2e.viewportHeight: 720
   - e2e.defaultCommandTimeout: 10000
   - e2e.video: false (for faster local runs)
   - e2e.screenshotOnRunFailure: true
4. Create cypress/support/ directory structure
5. Create cypress/fixtures/ directory for test data
6. Run npm install to install Cypress
  </action>

  </verify>

    - cypress/ directory structure created
  </acceptance_criteria>
  <done>Cypress installed and configured with base URL pointing to ASP.NET Core app</done>

<task type="auto">
  <name>Task 2: Create Custom Commands for Authentication</name>
  <files>cypress/support/commands.js, cypress/support/e2e.js, cypress/fixtures/users.json</files>
  <read_first>
    - Controllers/UserController.cs (understand login/signup/logout endpoints and form fields)
    - Views/User/LogInView.cshtml (identify form field names and selectors)
    - Views/User/SignUpView.cshtml (identify form field names and selectors)
    - Views/Shared/_Layout.cshtml (identify logout button selector)
  </read_first>
  <action>
1. Create cypress/fixtures/users.json with:
   - validUser: { email: "test@example.com", password: "Test123!", username: "testuser" }
   - newUser: { email: "new@example.com", password: "New123!", username: "newuser" }
   - invalidUser: { email: "invalid@example.com", password: "wrong", username: "invalid" }

2. Create cypress/support/commands.js with custom commands:
   - cy.login(email, password): Visit /user/log-in, fill email and password fields, submit form, wait for redirect to home
   - cy.signup(email, password, username): Visit /user/sign-up, fill email, password, and username fields, submit form, wait for redirect to home
   - cy.logout(): Click logout button in navbar, wait for redirect to login page
   - cy.createSession(email, password): Login via API (POST request) to set session without UI interaction

3. Create cypress/support/e2e.js with:
   - Import ./commands.js
   - Add global beforeEach hooks if needed (e.g., clear cookies/session)

4. Update cypress.config.js to add:
   - e2e.specPattern: "cypress/e2e/**/*.cy.{js,jsx,ts,tsx}"
   - e2e.supportFile: "cypress/support/e2e.js"
  </action>
  <verify>
    <automated>test -f cypress/support/commands.js && test -f cypress/support/e2e.js && test -f cypress/fixtures/users.json && grep -q "Cypress.Commands.add" cypress/support/commands.js && echo "PASS" || echo "FAIL"</automated>
  </verify>
  <acceptance_criteria>
    - cypress/support/commands.js contains cy.login() command
    - cypress/support/commands.js contains cy.signup() command
    - cypress/support/commands.js contains cy.logout() command
    - cypress/support/e2e.js imports commands.js
    - cypress/fixtures/users.json contains validUser, newUser, and invalidUser fixtures
    - All form selectors match actual form fields in LoginView.cshtml and SignUpView.cshtml
  </acceptance_criteria>

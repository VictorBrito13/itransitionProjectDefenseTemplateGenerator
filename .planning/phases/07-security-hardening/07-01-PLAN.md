# Plan 07-01: Session-gating + IDOR prevention

**Wave:** 1 (independent)
**Goal:** Add session validation to all unprotected endpoints, enforce private-template access control, filter `IsPublic` in search/user queries, prevent user enumeration.

## Tasks

### Task 1: Add session validation to unprotected endpoints

**Files:** `Controllers/Templates.cs`, `Controllers/UserController.cs`

Add `Auth.ValidateSession(HttpContext)` check (returning 401) to these endpoints:

| Endpoint | Current behavior | Fix |
|---|---|---|
| `GET /user/get-by-username?username=` | No auth check, returns user data | Add session check, return 401 if missing |
| `GET /template/template/user?userId=&page=&limit=` | No auth check, returns all templates | Add session check, return 401 if missing |
| `GET /template/get-template?templateId=` | No auth check, returns any template incl. private | Add session check + IsPublic/ownership check |
| `GET /template/get-by-query?text=` | No auth check, searches all templates | Add session check + IsPublic filter |
| `GET /template/likes?templateId=` | No auth check, returns likes | Add session check |

### Task 2: Private template access control

**Files:** `Controllers/Templates.cs`, `Services/Template/Template.cs`

For `GET /template/get-template`:
- If template `IsPublic == true` → return to any authenticated user
- If template `IsPublic == false` → only return if requesting user is an admin/owner of the template (check via `AdminService.IsUserAdmin()`)

```csharp
// In GetTemplate action:
if (!template.IsPublic)
{
    bool isAdmin = await _adminService.IsUserAdmin(userSession.UserId, templateId);
    if (!isAdmin)
        return JsonResponse.Error("Template not found", 404); // Don't reveal existence
}
```

### Task 3: IsPublic filtering in service layer

**Files:** `Services/Template/Template.cs`

- `GetTemplatesByQuery`: add `.Where(t => t.IsPublic == true)` to the SQL query or switch from `FromSqlRaw` to LINQ if possible
- `GetTemplatesByUserId`: add `.Where(t => t.IsPublic == true)` — or if the requesting user is querying their own templates, show all; if querying another user's, show only public

For `GetTemplatesByUserId`, current signature: `GetTemplatesByUserId(page, limit, userId)`. To distinguish "my templates" vs "another user's templates", either:
- Add a `requestingUserId` parameter and show all when `requestingUserId == userId`
- Or handle the filter at the controller level

**Recommended:** change the controller to pass the session user ID and filter at the service level:
```csharp
// Updated controller:
public async Task<IActionResult> GetTemplatesByUserId([FromQuery] int page, [FromQuery] int limit, [FromQuery] ulong userId) {
    Models.User? userSession = Auth.ValidateSession(HttpContext);
    if (userSession == null) return JsonResponse.Error("Unauthorized", 401);
    Models.Template[] templates = await _TemplateService.GetTemplatesByUserId(page, limit, userId, userSession.UserId);
    return JsonResponse.Ok(templates);
}

// Updated service:
public async Task<Models.Template[]> GetTemplatesByUserId(int page, int limit, ulong targetUserId, ulong requestingUserId) {
    return await _context.Templates
        .Include(t => t.Admins)
        .Where(t => t.Admins.Any(a => a.UserId == targetUserId)
            && (t.IsPublic || targetUserId == requestingUserId))
        .Skip(page * limit)
        .Take(limit)
        .ToArrayAsync();
}
```

### Task 4: Prevent user enumeration

**Files:** `Controllers/UserController.cs`

`GET /user/get-by-username` currently returns user data (email, username) to anyone. Fix:
- Add session validation (401 if not authenticated)
- Consider returning minimal info (just existence boolean) if the purpose is to check username availability during sign-up — or gate the entire endpoint behind auth and only return to authenticated users

**Recommended:** keep the endpoint but require session. The username lookup is used during template creation to find users to add as admins, so authenticated users need it.

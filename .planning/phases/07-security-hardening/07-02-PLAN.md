# Plan 07-02: Anti-CSRF token enforcement + session cookie hardening

**Wave:** 2 (blocked on Wave 1 — requires refactored controllers)
**Goal:** Add anti-CSRF protection on all state-changing POST/PUT/DELETE endpoints, harden session cookie configuration, and verify all changes pass the test suite.

## Tasks

### Task 1: Add anti-CSRF validation globally

**Files:** `Program.cs`

Add the auto-validation filter globally so all POST/PUT/DELETE actions require a valid anti-CSRF token:

```csharp
// In Program.cs, after builder.Services.AddControllersWithViews():
builder.Services.AddAntiforgery(options =>
{
    options.HeaderName = "X-CSRF-TOKEN";
    options.Cookie.Name = ".AspNetCore.Antiforgery";
    options.Cookie.HttpOnly = true;
    options.Cookie.SameSite = SameSiteMode.Strict;
    options.Cookie.SecurePolicy = CookieSecurePolicy.Always;
});
```

For controllers that return JSON from POST/PUT/DELETE (like `TemplateController.CreateTemplate`, `QuestionController.AddQuestions`, `ResponseController.SaveResponses`), the header-based token validation works with JavaScript `fetch` calls.

### Task 2: Add CSRF token to Razor forms

**Files:** All Razor views with `<form>` elements

Add `@Html.AntiForgeryToken()` to all forms. Key views to check:
- `Views/User/LogInView.cshtml`
- `Views/User/SignUpView.cshtml`
- `Views/Template/CreateTemplate.cshtml`

For JavaScript-based form submissions (e.g., `createTemplate.js`), read the token from a meta tag or cookie and include it as the `X-CSRF-TOKEN` header:

```html
<!-- In _Layout.cshtml or each view that uses JS POST -->
@inject Microsoft.AspNetCore.Antiforgery.IAntiforgery Antiforgery
@{
    var token = Antiforgery.GetAndStoreTokens(Context).RequestToken;
}
<meta name="csrf-token" content="@token">
```

```javascript
// In JS files that make POST/PUT/DELETE requests:
const csrfToken = document.querySelector('meta[name="csrf-token"]')?.content;
fetch(url, {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'X-CSRF-TOKEN': csrfToken
    },
    body: JSON.stringify(data)
});
```

### Task 3: Harden session cookie

**Files:** `Program.cs`

Update session configuration for secure defaults:

```csharp
builder.Services.AddSession(options =>
{
    options.IdleTimeout = TimeSpan.FromMinutes(60);
    options.Cookie.HttpOnly = true;
    options.Cookie.IsEssential = true;
    options.Cookie.SameSite = SameSiteMode.Strict;  // Was Lax
    options.Cookie.SecurePolicy = CookieSecurePolicy.Always;  // Was not set
});
```

### Task 4: Add `[AutoValidateAntiforgeryToken]` attribute

**Files:** All controllers with POST/PUT/DELETE endpoints

Apply at the controller level to validate tokens on all state-changing requests. Skip on controllers that only serve GET views.

```csharp
// Apply globally in Program.cs, or per-controller:
services.AddControllersWithViews(options =>
{
    options.Filters.Add<AutoValidateAntiforgeryTokenAttribute>();
});
```

**Important:** The `POST /user/log-in` and `POST /user/sign-up` endpoints use form URL-encoded data. Anti-forgery validation works with form posts as long as `@Html.AntiForgeryToken()` is present in the form. Verify these endpoints work after enabling the filter.

For JSON API endpoints (`/template/create`, `/question/add`, `/response/add`), the header-based token (`X-CSRF-TOKEN`) must be included by the JS client. Update the JS files.

### Task 6: Integration tests for CSRF

**Files:** `tests/ItransitionTemplates.Tests.Integration/`

- Test that POST without CSRF token returns 400
- Test that POST with valid CSRF token succeeds
- Update `CustomWebApplicationFactory` to configure anti-forgery for tests

```csharp
[Fact]
public async Task CreateTemplate_WithoutCsrf_ReturnsBadRequest()
{
    await _factory.InitializeDatabaseAsync();
    var authClient = await _factory.CreateAuthenticatedClientAsync();

    var template = new { title = "Test", topicId = 1 };
    var content = new StringContent(JsonSerializer.Serialize(template), Encoding.UTF8, "application/json");

    // POST without CSRF header
    var response = await authClient.PostAsync("/template/create", content);

    // Should be rejected by anti-forgery
    Assert.Equal(HttpStatusCode.BadRequest, response.StatusCode);
}
```
